## 3. 競合環境に対する「おかもし」サイト構造の勝ち筋

1. **「日程・会場・範囲・CTA」の一元完結性（`#schedule-selector`）**:
   - トップページ上で学年タブ（小6 / 中1 / 中2 / 中3）× 月号ピルを切り替えるだけで、実施日程・会場・Googleマップ・時間割・持参物・出題範囲・締切・申込ボタンまで 1 スクロール内で確認可能。
   - **D1 連動リアルタイム更新**: 事務局のスプレッドシート更新から GAS で即時 D1 へ反映されるため、静的ページ手動書き換えのタイムラグや情報不整合が発生しない。
2. **フォーム離脱率を極小化する申込 UX（`/apply/`）**:
   - 郵便番号 7 桁自動住所補完（`/api/address`）、学校名インクリメンタルサジェスト（`/api/schools`）、`localStorage` 自動下書き保存、コンビニ決済締切（3日前）リアルタイム警告＋ 3 分解説動画（R2）アコーディオンの組込みにより、保護者（主にスマートフォン入力）の迷いと入力エラーを低減。
3. **旧サイト（WordPress）SEO 資産の無損失継承**:
   - 旧 URL パターン（`/touitsu-moshi/`, `/tekisei-moshi/`, `/school-list/*`, `/2018/*`〜`/2026/*`, `/wp-*` 等）を `_redirects` の 301 ルールと `404.html` 即時転送で受け止め、検索流入・外部被リンクのリンク切れを防止。
4. **安心感と視認性の両立（教育機関デザイン規律）**:
   - フォレストグリーン（`#134230`）による学術的信頼感と、申込 CTA 専用バーントオレンジ（`#C2410C` / `orange-700`）の明確な役割分離、および会場名・注釈の切り捨て禁止ルールにより、保護者の見落としトラブルを構造的に防止。
